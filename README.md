# ⛴️ Real-Time Ferry Ticket Sales & Redemption Analytics

## Project Overview

This project analyzes ferry ticket sales and redemption data for Toronto Island Park to identify passenger demand patterns, peak travel hours, and operational insights. The solution includes data preprocessing, exploratory data analysis (EDA), KPI generation, and an interactive Streamlit dashboard.

---

## Objectives

- Analyze historical ferry ticket sales
- Analyze ticket redemption trends
- Identify peak and off-peak travel periods
- Calculate net passenger movement
- Support operational planning through interactive dashboards
